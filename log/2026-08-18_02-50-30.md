# Change Log: 2026-08-18 02:50:30

## Summary of Modifications

1. **Fixed Frequent WhatsApp Logout Issue**:
   - Identified root cause: `logout()` previously spawned duplicate background threads calling `client.connect()` concurrently on the same session database, and premature file deletions were triggered during normal WhatsApp 515 reconnect handshakes.
   - Refactored `WhatsAppService` (`backend/app/services/whatsapp.py`) to use property-based authentication checks (`client.is_logged_in` and `client.is_connected`).
   - Implemented a single protected worker thread with reconnect backoff.
   - Stopped premature SQLite session wipes during temporary websocket stream reconnects.

2. **Updated API Status Endpoint**:
   - Enhanced `/api/whatsapp/status` in `backend/app/main.py` to evaluate persistent database authentication status (`logged_in`), preventing modal flickering during transient reconnects.
