# Change Log: 2026-08-18 02:09:00

## Summary of Modifications

1. **Architecture & Directory Restructuring**:
   - Split application into two dedicated folders:
     - `backend/`: FastAPI backend with WhatsApp service (`neonize`), CSV storage (`csv_service.py`), crypto verification, and REST API. Ready for deployment on Render.
     - `frontend/`: Static web assets (`index.html`, `participants.html`, `data.html`, `health.html`, `scan_result.html`, `config.js`). Ready for deployment on GitHub Pages (`github.io`).

2. **WhatsApp Automation & Session Management**:
   - Implemented QR code retrieval endpoint (`/api/whatsapp/qr` and `/api/whatsapp/status`) to display QR directly in the frontend modal when WhatsApp is not logged in.
   - Added automatic session DB cleanup (`my_session.sqlite3` deletion) if the service is inactive for >2 days or upon logout.

3. **CSV Data Storage**:
   - Replaced Google Sheets dependency with `CSVService` (`transactions.csv`).
   - Added CSV download endpoint (`/api/csv/download`) and button on the frontend data dashboard.

4. **Configuration & Dependency Fixes**:
   - Added `pydantic-settings` to `backend/requirements.txt`.
   - Updated `backend/app/config.py` to make `SHEET_URL` optional.
   - Added `frontend/config.js` for flexible backend URL configuration.
