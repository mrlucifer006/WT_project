# Change Log: 2026-08-18 02:41:30

## Summary of Modifications

1. **Fixed Neonize QR Callback Interception**:
   - In `neonize`, login QR codes are dispatched through the specialized callback decorator `@client.event.qr` (which receives raw QR data bytes), rather than generic protobuf event listeners.
   - Updated `backend/app/services/whatsapp.py` to register `@self.client.event.qr`, correctly capturing the QR code string into `self.qr_code`.

2. **Added Direct QR PNG Image Endpoint**:
   - Implemented `GET /api/whatsapp/qr_image` in `backend/app/main.py`, which generates and returns a direct PNG image (`image/png`) of the active WhatsApp login QR.
   - Updated `frontend/index.html` to display the QR image directly from `/api/whatsapp/qr_image`, removing external API dependencies.
